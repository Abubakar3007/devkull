# Devkull Connect Hub

Create a modern, premium, enterprise-style website for my technology company **Devkull**.

## Company

**Brand:** Devkull
**Email:** [info@devkull.in](mailto:info@devkull.in)
**Primary focus:** Salesforce customization, Salesforce integrations, e-commerce integrations, custom web solutions.

Devkull helps businesses connect Salesforce with e-commerce platforms, automate business workflows, customize Salesforce, and build scalable digital solutions.

The website should look like a **high-end Salesforce consulting + technology integration agency**, not like a generic freelancer website.

---

# 1. Overall Design Direction

Create a website that feels:

* Premium
* Modern
* Enterprise-grade
* Minimal
* Trustworthy
* Technology-focused
* Conversion-focused
* Fast and responsive

Visual inspiration should be closer to modern SaaS/technology companies than traditional IT service companies.

Use:

* Clean typography
* Large headlines
* Spacious sections
* Subtle gradients
* Modern cards
* Soft shadows
* Rounded corners
* Professional animations
* Interactive hover effects
* Smooth scrolling
* Subtle background grid/particles where appropriate

Avoid:

* Cheap-looking stock photos
* Excessive animations
* Overcrowded layouts
* Generic corporate templates
* Too many colors
* Cartoon-style graphics

Use a professional color system with a dark navy/black foundation and Salesforce-inspired blue accents, combined with white/light sections for contrast.
